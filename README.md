### 🔍 FZF Navigation

| Shortcut        | Action                |
|-----------------|------------------------|
| <Space>f        | Find Files             |
| <Space>g        | Live Grep              |
| <Space>b        | List Buffers           |
| <Space>h        | Command History        |

---

### 📂 Fern File Manager

| Shortcut        | Action                         |
|-----------------|----------------------------------|
| <Space>e        | Toggle Fern File Drawer         |
| <Enter>         | Open selected (Fern buffer)     |
| o               | Open selected (Fern buffer)     |
| s               | Open in horizontal split        |
| v               | Open in vertical split          |
| t               | Open in new tab                 |

---

### ⚙️ Code Formatting

| Shortcut             | Description                         |
|----------------------|-------------------------------------|
| v + <Space>f         | Format selection with clang-format  |

---

### 🧠 CoC Auto-completion (Insert Mode)

| Key             | Description                            |
|-----------------|----------------------------------------|
| <Enter>         | Confirm selected suggestion            |
| <Tab>           | Next suggestion                        |
| <S-Tab>         | Previous suggestion                    |

---

**Note**: `<Space>` represents the **leader key**, which has been remapped from the default (`\`) to **spacebar** for convenience.
